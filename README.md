# LIB3D
Lightweight 3D graphics engine for microcontrollers.

My BSc diploma project.

This README will be updated in the future.

Notes:
 - using hidden line elimination (HLE) with fixed point numbers may require changing L3D_FP_DP value in config and in model parser config.ini file
 - when using HLE, wireframe colour is not yet implemented
 - when using fixed point numbers with low precision, camera may not move as intended
